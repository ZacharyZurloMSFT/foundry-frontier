# Fictional Northwind help: How to report a loss

## Before you start

In an emergency, move to safety and contact local emergency services first, because this portal is not an emergency service.

Policyholders sign in with Microsoft Entra, and the server assigns the role of each account.

Only policyholder accounts see the Report a loss page.

Use synthetic information only, because this demonstration is not for real losses or real personal details.

## Steps to report a loss

1. Sign in and open Report a loss in your account.
2. Select the policy, and the portal shows the insured vehicle that belongs to that policy.
3. Choose the incident type, which can be auto collision, auto hail or other auto loss.
4. Enter the loss date, which cannot be in the future.
5. Enter the two-letter US state abbreviation for the place where the loss happened, such as WA.
6. Describe the loss in the What happened field, using between 10 and 2,000 characters.
7. Tick the checkbox that confirms the report contains synthetic information only.
8. Select Submit loss report one time.

## After you submit

The portal shows a claim number for the new case, and a policyholder should keep that claim number.

A submitted report opens a case for human review, and a report does not decide coverage or authorize a payment.

The portal sends no external emails, text messages or phone calls about a report.

## If the connection fails

If the connection fails or the result is unclear, open My claims first to check whether the report was saved.

The portal never resubmits a report automatically, so a policyholder must choose to retry.

If the report is not listed in My claims, submit the exact same report again.

A retry of the exact same report returns the original claim instead of creating a duplicate when the first attempt was saved.

A retry with any changed detail is a different report, so check My claims before changing anything.

## Review flags

When the loss date, the loss state or the policy wording period does not match the policy record, the portal records a review flag for a human reviewer.

A review flag is not a denial, and a person reviews the report together with its flags.

Northwind Insurance is a fictional insurer, and this help article about reporting a loss is a synthetic demonstration, not a coverage decision.
