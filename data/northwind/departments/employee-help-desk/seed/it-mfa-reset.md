# MFA Reset

**Doc ID:** IT-430

## Self-serve reset (recommended)

If you still have access to any registered factor, use self-serve reset:

1. Go to `aka.ms/mfasetup` from any browser.
2. Sign in with `@northwind.com`.
3. Approve MFA with a working factor.
4. Add a new factor (Authenticator app is preferred; SMS backup is
   permitted for field adjusters without smartphones).
5. Delete the lost/broken factor from the list.

The process takes about 5 minutes.

## No working factor

If you have **no working factor** (lost phone, revoked hardware token):

1. Contact the IT help desk at `+1-800-555-0142` **from a verified
   contact number** — the help desk will call back on the number IT has
   on file to confirm identity.
2. Have your **employee ID and current manager's name** ready.
3. IT will issue a **temporary access pass (TAP)** valid for 24 hours.
4. Use the TAP at `aka.ms/mfasetup` to register a new factor.

Managers cannot approve MFA resets on behalf of an employee — this is
an anti-social-engineering guardrail. Do not follow social-media DMs
claiming to be from IT.
